# CRUD simple

Guía inicial para futuras operaciones sobre una entidad simple, únicamente cuando exista un esquema aprobado.

- Leer `AGENTS.md` y `database/01_Crear_Base_Datos.sql` antes de trabajar.
- No asumir nombres ni tipos de tablas o columnas.
- Usar ADO.NET con SQL parametrizado.
- No modificar el esquema sin permiso explícito.
